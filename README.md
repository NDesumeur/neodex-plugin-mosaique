# Mosaïque

Des grilles à noircir d'après les nombres des lignes et des colonnes. Chaque grille finie révèle une image en pixel art.

Chaque nombre à gauche d'une ligne (ou au-dessus d'une colonne) est la longueur d'un bloc de cases noires. Noircis les bonnes cases : la grille finie se colore et montre son image. 12 grilles, du cœur à la note de musique, et des grilles au hasard sans fin. Toute grille qui respecte les nombres est acceptée.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Mosaïque → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
